How to use this page

  • Press Start (or the space bar) to run the simulation and Pause to stop it.
  • Step advances one generation while paused.
  • Reset brings back the YELLOW starting pattern, and Clear empties the grid.
  • Click or drag on the grid to bring cells to life or remove them.

Every generation, all cells update at the same time using these rules:

  1. Underpopulation: a live cell with fewer than 2 live neighbours dies.
  2. Survival: a live cell with 2 or 3 live neighbours lives on.
  3. Overpopulation: a live cell with more than 3 live neighbours dies.
  4. Reproduction: a dead cell with exactly 3 live neighbours becomes alive.

The edges wrap around, so a cell on the right edge neighbours the cell on the left edge, and the top connects to the bottom.
